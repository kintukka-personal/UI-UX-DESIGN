A counting transition for numeric text

NumberRoll watches a text view that holds a number. When the value changes it doesn't swap the string — it rolls each digit that actually moved, upward when the number climbs and downward when it falls. Digits that didn't change stay put. Where motion is turned off, the text updates instantly and nothing is lost.

Watch the hundreds column: it only moves when it has to.

Other shapes of number

Separators, currency symbols and colons are columns too. They hold their place while the digits around them move, and cross-fade if they change.

Using it

One class, no dependencies. Point it at an element and hand it numbers.

// Attach to any element that will hold a number.
const counter = new NumberRoll(document.querySelector('#views'), {
  duration: 900,          // ms for one column's roll
  stagger: 45,            // ms between adjacent columns
  easing: 'smooth',      // smooth | overshoot | mechanical | linear
  lead: 'right',         // which end starts moving first
  format: v => v.toLocaleString('en-AU')
});

counter.set(1024);          // first call paints, no animation
counter.set(1025);          // ones column rolls up one notch
counter.set(998);           // everything rolls down, thousands column retires

counter.set(500, { direction: 1 });  // force an upward roll
counter.options.duration = 400;         // change settings whenever

Decisions worth knowing about

  • Direction follows the value. Going up rolls up, going down rolls down, and a digit takes the short way round — 9 to 1 climbing passes through 0, it doesn't reverse. Pass direction to override.
  • Columns are matched from the right. So 99 to 100 keeps the two nines where they are and grows a new column on the left, instead of re-rolling everything.
  • Widths animate on entry and exit. A digit appearing or retiring expands and collapses its own column, so the surrounding text never jumps.
  • Overshoot renders one extra digit. Past the target in the direction of travel, so a springy easing reveals the next number rather than empty space.
  • Reduced motion is honoured on load. If the system asks for less motion the text just changes, and the checkbox above lets you feel the difference.
  • Interrupted rolls settle first. Rapid updates finish the previous column instantly and start again, so the strip never drifts out of alignment.
Close cousin of SwiftUI's .contentTransition(.numericText()). The web has no built-in equivalent, so this builds the column mask by hand.
